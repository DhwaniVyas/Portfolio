# Dhwani Vyas — Portfolio

A responsive personal portfolio built with React, Vite, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

## Main features

- Porsche-inspired editorial visual direction: white, black, restrained red accents and bold condensed typography.
- No automotive hero photography. The hero uses a typographic introduction and a custom build-log panel.
- Responsive navigation and section transitions.
- Skills grouped by web development, AI/ML, programming, IoT and tools.
- Nine projects with a consistent image-led card layout, category filters and detail modals.
- Each project detail includes an overview, real-world application, key highlights and technology stack.
- Contact links for email, phone, GitHub and LinkedIn.
